# AGRADECIMENTOS

#### Jeff Thompson

Todo este código só foi possível graças a uma enorme quantidade de ajuda online e offline. Na medida do possível, procurei rastrear tutoriais específicos, threads de fóruns e artigos que contribuíram para exemplos específicos. Este livro não seria possível sem tantas pessoas compartilhando seu excelente trabalho abertamente.

### Exemplos construídos a partir de:

- **Círculo/Retângulo:** desenvolvido a partir do exemplo por [Matt Worden](http://vband3d.tripod.com/visualbasic/tut_mixedcollisions.htm).
- **Linha/Ponto:** via postagens da comunidade no [StackOverflow](http://stackoverflow.com).
- **Linha/Círculo:** via formulações de [Philip Nicoletti](http://www.codeguru.com/forum/showthread.php?threadid=194400).
- **Linha/Linha:** construído a partir dos exemplos geométricos de [Paul Bourke](http://paulbourke.net/geometry/pointlineplane/) e [Ibackstrom](http://community.topcoder.com/tc?module=Static&d1=tutorials&d2=geometry2).
- Muitas e muitas horas dedicadas a discussões e tiragem de dúvidas no **StackOverflow**.

### Agradecimentos especiais a:

- **Ben Fry** e **Casey Reas**, criadores do [Processing](https://processing.org), e a toda a incrível comunidade de criadores que utilizam essa ferramenta.
- **John Gruber**, criador do [Markdown](http://daringfireball.net/projects/markdown/syntax), linguagem em que o livro original foi escrito.
- Ferramentas open-source como **jQuery**, **MAMP** e bibliotecas de código aberto que alimentaram a primeira versão web deste livro.
