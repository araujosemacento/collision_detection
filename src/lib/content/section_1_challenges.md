# SEÇÃO 1: DESAFIOS

![Ilustração de Desafio](images/challenge.jpg)

Tente estes desafios para exercitar e modificar os algoritmos que escrevemos até agora. Não se frustre se não conseguir resolver todos, alguns realmente são pensados para programadores mais experientes:

1. **Mudança de Cor**: Tente alterar a cor das formas quando colidirem (ex: mudar para verde ou vermelho ao invés de laranja).
2. **Efeitos Visuais**: Você consegue fazer com que um objeto mude de tamanho ou seja empurrado para longe quando ocorrer uma colisão?
3. **Zona de Buffer no Ponto/Ponto**: Nossa colisão [Ponto/Ponto](point-point) é extremamente rígida: você precisa estar no pixel *exato* do outro ponto. Você consegue modificar a função para incluir uma "margem de tolerância" (*buffer zone*) onde a colisão é detectada mesmo que os pontos não estejam perfeitamente alinhados?

Dica: Para o Desafio 3, pense em como o cálculo de distância que aprendemos em [Ponto/Círculo](point-circle) pode ser aplicado!
